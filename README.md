# Bougassaaa squad

A browser fan game with six tactical arenas, escalating patrols, walls, keys, lasers, dash, rescue bonuses and milestone graphics.

- Choose to play as Bougassaaa, Frira, Bingo or 7idan; the other three become rescue targets.
- Languages: Moroccan Darija (Arabic script, right-to-left), English, French and Spanish.
- Works with touch controls or arrow/WASD keys. Space waits one turn.
- Each visitor starts a separate game. Progress and chosen language are stored only in that browser; no Wabi save is included.
- No account, payment, analytics or backend is required.

This is an unofficial fan game. Character/profile artwork and the 21.com milestone logo belong to their respective owners; no sponsorship or affiliation is claimed. The logo is not a link and the game has no wagers or purchases.

## Run locally
Serve this directory with any static HTTP server, for example `python3 -m http.server 8000`.

The deployed files are `index.html`, `app.js`, `style.css`, `icon.svg` and `assets/`. Editable source is under `src/`. `app.js` includes React, licensed under MIT; its bundled license notice is retained.
